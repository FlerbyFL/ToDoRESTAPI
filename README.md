# ToDo REST API

## Hi, this is my first project using the REST API. In this project, I tried to meet all the REST API requirements, as well as correctly handle errors and various data vulnerabilities.

## Brief description of the project
### This ToDo list has the following functions:
1. add a task
2. view all tasks
3. view only uncompleted tasks
4. complete a task
5. delete a task

### All these functions are distributed using routing
